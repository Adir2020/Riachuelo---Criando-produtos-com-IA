# 📅 Cronograma Semanal de Estudos (30 Dias)

Acompanhe aqui o seu progresso diário ao longo das 4 semanas de estudos em QA.

---

## 🚀 Semana 1 — Fundamentos de QA

> **Objetivo:** Compreender os conceitos básicos de QA, ciclo de vida de software, tipos de teste e criação de cenários/casos de teste.

- [ ] **Dias 1–2:** QA, conceitos de testes e ciclo de vida do desenvolvimento de software.
- [ ] **Dias 3–4:** Tipos de testes (funcional, regressão, smoke test e teste exploratório).
- [ ] **Dias 5–6:** Elaboração de casos de teste e cenários de teste.
- [ ] **Dia 7 (Prática):** Criar 10 casos de teste e identificar 3 bugs em uma aplicação de treino.

## 🧪 Semana 2 — Testes Funcionais

> **Objetivo:** Aprofundar em técnicas de testes manuais, escrita de bug reports detalhados e validações de formulários.

- [ ] **Dias 8–9:** Testes positivos/negativos e técnicas básicas de design de testes (Ex: Particionamento por Equivalência, Análise de Valor Limite).
- [ ] **Dias 10–11:** Escrita de Bug Report (Título, passos para reprodução, resultado esperado vs. obtido, prioridade e severidade).
- [ ] **Dias 12–13:** Testes de formulários e validações de campos (entradas válidas/inválidas, limites de caracteres, etc.).
- [ ] **Dia 14 (Prática):** Criar 15 casos de teste e 3 bugs documentados com rigor técnico.

📌 *Materiais da Semana:* Ver [recursos.md - Semana 2](file:///c:/Users/evand/Desktop/PASTA%20IA/recursos.md#semana-2--testes-funcionais)

---

## ⚡ Semana 3 — API e Automação

> **Objetivo:** Aprender fundamentos de arquitetura Web/HTTP, testes manuais de API com Postman e introdução à automação de testes.

- [ ] **Dias 15–16:** Protocolo HTTP, métodos (GET, POST, PUT, DELETE), status codes (2xx, 4xx, 5xx) e formato JSON.
- [ ] **Dias 17–18:** Testes de API na prática utilizando Postman (coleções, variáveis e validações básicas).
- [ ] **Dias 19–20:** Fundamentos e conceitos de automação de testes (locators, seletores, asserções).
- [ ] **Dia 21 (Prática):** Testar uma API real/mock com 5 requisições e suas respectivas validações.

📌 *Materiais da Semana:* Ver [recursos.md - Semana 3](file:///c:/Users/evand/Desktop/PASTA%20IA/recursos.md#semana-3--api-e-automação)

## 🛠️ Semana 4 — Git, CI/CD e Projeto Final

> **Objetivo:** Integrar controle de versão, esteira de integração contínua e consolidar todo o aprendizado em um projeto para portfólio.

- [ ] **Dias 22–23:** Git básico (commits, branches, push, pull e pull requests).
- [ ] **Dias 24–25:** Conceitos de CI/CD e execução de testes em pipelines (ex: GitHub Actions).
- [ ] **Dias 26–27:** Organização da estrutura de projetos de QA e documentação de testes.
- [ ] **Dias 28–30 (Projeto Final):** Elaboração e finalização do projeto prático contendo casos de teste, bugs documentados, testes de API e scripts de automação.
